## Gotchas

- The hybrid's calibration assumes both clusters run the 4% stop list; without it, `cmd/tracklist` found 264 instead of 268 of set044's songs.
- A Mac on battery with nobody at it sleeps mid-run: every process freezes and the stream server bursts the backlog on wake. The real-time harness holds caffeinate and flags runs whose windows stopped arriving.

- `grep -c` exits 1 at zero matches; do not chain commits after it with `&&`.
- Benchmarks (capacity, failover timing) need AC power, lid open, battery done charging; never edit tracked files while they run.
- Ask before installing audfprint or Panako (Panako needs Java).
