## Gotchas

- librosa's beat tracker segfaults in this Python (3.13, numba 0.68); `eval/dj_bpm.py` uses only its tempo estimate. A segfaulting multiprocessing worker looks like a deadlock (workers at 0% CPU forever).
- ffmpeg sends a paced file's first 0.5 s at once (`-readrate_initial_burst`).
- macOS tops the battery up from 99% now and then; real-time runs then flag themselves invalid and need a rerun.
