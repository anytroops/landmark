or try a song from the test set

Landmark searches every clip two ways: with pair hashes, as classic fingerprinting does, and with triplet hashes built from ratios a tempo change cannot move. Try a test song at +6% to see the difference.

Name every song in a DJ mix, and how it was mixed in

Every 10 s window, about 2.5 s apart, gets six searches, cut from one shared front end. The decoder reports a song once its first window is certain, as live monitoring does; then each song's fades, tempo change, and BPM are read from the audio.
